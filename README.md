# صفحة روابط شَجَن

مشروع عربي متجاوب يعمل كصفحة روابط مصغرة، مع لوحة إدارة لتخصيص الصفحة وإضافة الروابط وترتيبها ومتابعة الزيارات والنقرات.

## الملفات الرئيسية

- `index.html`: الصفحة العامة للزوار.
- `admin.html`: لوحة التحكم.
- `css/`: ملفات التنسيق.
- `js/config.js`: إعداد اتصال Supabase.
- `js/app.js`: تشغيل الصفحة العامة وتسجيل الزيارات والنقرات.
- `js/admin.js`: إدارة المظهر والروابط والتحليلات.
- `supabase/schema.sql`: إنشاء قاعدة البيانات والسياسات ومساحة الصور.

## التشغيل السريع محليًا

يمكن فتح `index.html` مباشرة. سيعمل المشروع في **الوضع المحلي التجريبي**، وتُحفظ البيانات والإحصاءات في متصفحك فقط.

للاستخدام الحقيقي على GitHub Pages وجمع إحصاءات جميع الزوار، يجب ربط المشروع بـSupabase.

## ربط Supabase

### 1. إنشاء المشروع

1. افتحي موقع Supabase وأنشئي مشروعًا جديدًا.
2. من القائمة افتحي **SQL Editor**.
3. انسخي محتوى الملف `supabase/schema.sql` كاملًا وشغّليه.

### 2. إنشاء مستخدم الإدارة

1. افتحي **Authentication** ثم **Users**.
2. اختاري **Add user**.
3. أدخلي بريدك وكلمة مرور قوية.
4. عطّلي التسجيل العام من إعدادات Authentication حتى لا يستطيع أي شخص إنشاء حساب إدارة.

### 3. إدخال بيانات الاتصال

من Supabase افتحي:

`Project Settings > API`

ثم انسخي:

- `Project URL`
- `anon public key`

وضعيهما داخل `js/config.js`:

```js
window.SHAGEN_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT.supabase.co",
  supabaseAnonKey: "YOUR_ANON_PUBLIC_KEY",
  adminUsername: "admin",
  adminEmail: "your-admin-email@example.com",
  localAdminPassword: "ChangeMe2026!"
};
```

> لا تضعي مفتاح `service_role` داخل المشروع؛ لأنه مفتاح سري.

## الرفع على GitHub

1. أنشئي مستودعًا جديدًا في GitHub.
2. ارفعي جميع ملفات المشروع مع المحافظة على المجلدات.
3. افتحي:
   `Settings > Pages`
4. في **Build and deployment** اختاري:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. احفظي الإعدادات.
6. ستظهر الصفحة على رابط GitHub Pages الخاص بالمستودع.

الصفحة العامة:

`https://USERNAME.github.io/REPOSITORY/`

لوحة التحكم:

`https://USERNAME.github.io/REPOSITORY/admin.html`

## طريقة الاستخدام

من لوحة التحكم يمكنك:

- تغيير اسم الصفحة والوصف ونص الحقوق.
- رفع شعار أو وضع رابط مباشر للشعار.
- اختيار لون للخلفية أو رفع صورة.
- تغيير ألوان الأزرار وشكل الحواف والظل.
- إضافة روابط غير محدودة.
- تحديد أيقونة لكل رابط.
- إظهار الرابط أو إخفاؤه.
- فتح الرابط في الصفحة نفسها أو في صفحة جديدة.
- ترتيب الروابط بالسحب والإفلات.
- مشاهدة إجمالي الزيارات والنقرات والنقرات لكل رابط.

## ملاحظات مهمة

- رفع الصور إلى Supabase متاح بعد تسجيل الدخول.
- الحد المقترح للصورة 5 ميجابايت.
- الإحصاءات في الوضع المحلي تخص المتصفح نفسه فقط.
- الإحصاءات في وضع Supabase تجمع بيانات جميع الزوار.
- لتغيير رقم واتساب الافتراضي عدّلي الرابط من لوحة التحكم.


## دخول لوحة الإدارة باسم مستخدم وكلمة مرور

- افتحي `admin.html`.
- اسم المستخدم هو القيمة الموجودة في `adminUsername` داخل `js/config.js`.
- كلمة المرور هي كلمة مرور مستخدم الإدارة الذي أنشأتِه في Supabase Authentication.
- `adminEmail` هو بريد ذلك المستخدم، لكنه لا يظهر كحقل دخول للزائرة؛ الإدخال في صفحة الإدارة يكون **اسم مستخدم + كلمة مرور** فقط.
- للاختبار المحلي قبل ربط Supabase يستخدم المشروع `localAdminPassword`، لكن هذا ليس حماية مناسبة لموقع منشور.
- لكي تنعكس إضافة/تعديل/حذف الروابط على الموقع لجميع الزوار، يجب إكمال ربط Supabase وتشغيل `supabase/schema.sql`.
